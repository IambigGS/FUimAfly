# PRD & Build Execution Plan: Incremental Android APK v1.5 (`FUimAfly_v1.5.apk`)

**Author:** Atlas — Performance & Build Master  
**Date:** 2026-08-13  
**Status:** Proposal / Approved  

## TL;DR Summary
The build pipeline for `FUimAfly_v1.5.apk` updates `versionCode` to `2` and `versionName` to `"1.5"` inside `android/app/build.gradle`. The sequence follows:
1. `npm run build`
2. `npx cap sync android`
3. `cd android; .\gradlew.bat assembleDebug`
4. Copy generated `app-debug.apk` to `APKs/FUimAfly_v1.5.apk`.

Existing APKs (`v1.0`, `v1.1`, `v1.2`, `v1.3`, `v1.4`) in the `APKs/` directory will remain untouched.

## 1. System Requirements & Settings
- **Target Android Namespace:** `com.steve.fuimafly`
- **Gradle Version Code:** `2`
- **Gradle Version Name:** `"1.5"`
- **Frame Rate Target:** Locked 60 FPS on Android WebView

## 2. File Updates
Modify `android/app/build.gradle` under `defaultConfig`:
- Update `versionCode 1` -> `versionCode 2`
- Update `versionName "1.0"` -> `versionName "1.5"`

## 3. Verification Steps
1. Verify `android/app/build.gradle` reflects `versionCode 2` and `versionName "1.5"`.
2. Confirm presence of `FUimAfly_v1.0.apk` through `FUimAfly_v1.4.apk` in `APKs/`.
3. Confirm creation of `APKs/FUimAfly_v1.5.apk`.
